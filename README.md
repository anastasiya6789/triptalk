# 🧳 TripTalk — английский для путешествий

Веб-приложение в стиле Duolingo для тех, кто едет за границу: аэропорт, отель, улица, транспорт, магазин, кафе и экстренные ситуации.

## Что внутри

- **Учиться**: 8 разделов по ситуациям, в каждом 4 урока: новые слова, ещё слова, фразы и повторение. Упражнения:
  - выбрать перевод (EN→RU и RU→EN)
  - аудирование (выбрать услышанное, можно медленно 🐢)
  - написать слово (небольшие опечатки засчитываются)
  - собрать предложение из слов
  - найти пары
  Ошибки возвращаются в конец урока, как в Duolingo.
- **Карточки**: интервальное повторение. Слова сами возвращаются через 1, 2, 4, 7, 15, 30 дней.
- **Грамматика**: курс из 16 тем в 4 блоках.
  - *Фундамент*: местоимения he/she/it, to be, артикли, порядок слов.
  - *Вопросы и просьбы*: вопросы, вежливые просьбы, there is/are.
  - *Времена*: карта времён, Present Simple, Present Continuous, Past Simple, будущее, Present Perfect.
  - *Детали*: предлоги, much/many/some/any, can/must/have to/should.
  В каждой теме есть объяснение, типичные ошибки русскоговорящих, примеры с озвучкой и тест с заданиями «собери предложение».
- **Произношение и чтение**: 9 тем. Почему написание не совпадает с произношением; открытый и закрытый слог; сочетания гласных; немые буквы (почему could читается «куд»); th, sh, ch и правила для c и g; звуки, которых нет в русском; окончания -ed и -s; ритм и слияния (could you → «куджу»); трудные слова путешественника. Каждое слово можно послушать, а кнопкой 🎤 проверить своё произношение (Chrome, Safari, Edge).
- **Фразы с разбором**: перед тем как собрать фразу, ученик видит карточку «Новая фраза» с разбором по словам и пояснением. В заданиях русские слова подчёркнуты пунктиром: нажатие показывает перевод.
- **Разговорник**: все фразы и слова с озвучкой и живые диалоги, которые можно проиграть.
- **Профиль**: XP, уровни, серия дней 🔥, цель дня, достижения, резервная копия прогресса.
- **Регистрация**: email и пароль, плюс гостевой режим. Когда гость регистрируется, его прогресс переносится в аккаунт.

Озвучка работает через встроенный в браузер синтез речи, поэтому интернет и ключи для неё не нужны.

## Структура

```
index.html              — страница
css/style.css           — дизайн (светлая и тёмная тема, мобильная версия)
js/data.js              — слова, фразы (с разбором по словам), диалоги
js/grammar.js           — темы грамматики и тесты
js/pronunciation.js     — произношение и правила чтения
js/auth.js              — аккаунты и сохранение прогресса
js/firebase-config.js   — сюда вставляется конфиг Firebase (необязательно)
js/app.js               — логика приложения
```

Чтобы добавить слова или фразы, просто допиши строки в `js/data.js`. Формат описан в начале файла.

## Запуск локально

```bash
python3 -m http.server 8000
```

Потом открой http://localhost:8000

## Как залить на GitHub Pages

1. Создай новый репозиторий на github.com, например `triptalk`.
2. В папке проекта выполни:
   ```bash
   git init
   git add .
   git commit -m "TripTalk"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/triptalk.git
   git push -u origin main
   ```
3. В репозитории открой **Settings → Pages**. В разделе *Source* выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**.
4. Через минуту-две сайт будет доступен по адресу `https://ТВОЙ_ЛОГИН.github.io/triptalk/`.

## Регистрация: два режима

### Режим 1. Локальный (работает сразу)
Аккаунты и прогресс хранятся в браузере (localStorage). Если заходить с того же устройства и того же браузера, прогресс не теряется. На другом устройстве он виден не будет, но в профиле можно скачать прогресс в файл и загрузить его в другом месте.

> ⚠️ В этом режиме пароль хранится только в браузере в виде хэша. Это защита от случайной потери прогресса, а не настоящая безопасность. Для настоящих аккаунтов подключи Firebase.

### Режим 2. Облако Firebase (рекомендуется, бесплатно)
Прогресс синхронизируется между телефоном и компьютером, и появляется восстановление пароля.

1. Зайди на https://console.firebase.google.com и нажми **Add project**. Google Analytics можно выключить.
2. **Build → Authentication → Get started**, выбери **Email/Password** и включи (Enable).
3. **Build → Firestore Database → Create database**, выбери ближайший регион и *production mode*.
4. Во вкладке **Rules** в Firestore замени правила на эти и нажми **Publish**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /progress/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. **Authentication → Settings → Authorized domains → Add domain** и добавь `ТВОЙ_ЛОГИН.github.io`.
6. **Project settings** (шестерёнка) → *Your apps* → значок **</>** (Web). Зарегистрируй приложение и скопируй объект `firebaseConfig`.
7. Вставь его в `js/firebase-config.js`:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
8. Закоммить и запушь. Готово ✨

> `apiKey` от Firebase для веб-приложений не секретный: его можно публиковать на GitHub. Данные защищают правила из шага 4, по ним каждый пользователь видит только свой прогресс.
